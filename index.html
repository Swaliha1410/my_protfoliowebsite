Movie-Explorer

Movie-Xplorer - Premium Movie Discovery Platform Movie-Xplorer is a Netflix-inspired web application that allows users to browse, search, and explore movies using The Movie Database (TMDB) API. The platform features a stunning cinematic login page with a large glowing logo and blur effects, followed by a rich browsing experience with trending movies, genre filters, and personalized lists. Users can view detailed movie information in an elegant modal, watch trailers via YouTube integration, and manage their favorite movies and watch-later lists. The app includes advanced features like infinite scrolling, sorting options, grid/list view toggles, movie sharing capabilities, and a responsive design that works seamlessly across all devices. Built with vanilla JavaScript and modern CSS, it offers a premium streaming service aesthetic with smooth animations, glass-morphism effects, and an intuitive user interface.
